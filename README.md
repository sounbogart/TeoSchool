# TeoSchool

Основа статического сайта с примерами материалов по математике для 7–8 классов.
Содержимое разделов пока демонстрационное. Регистрации, личного кабинета и серверной части нет.

## Локальный запуск

Нужен Python 3; установка пакетов и сборка не требуются.

```sh
cd /workspace/Teach
python3 -m http.server 8000 --bind 127.0.0.1
```

Точка входа — `index.html`. В нём находятся стили, навигация и примеры материалов
в объекте `DATA`. Для остановки сервера нажмите Ctrl+C.

## Исходные материалы

Страница перенесена из `.github/workflows/static.yml`, где HTML ошибочно находился
вместо workflow YAML. Примеры материалов и навигация сохранены; исходная версия
доступна в Git-истории, в коммите `7923d5156abae5dc846b6b75424ddb3cf00c0e22`.

Workflow публикации не настроен. Хостинг, окончательное содержание и способ
публикации предстоит выбрать отдельно.
